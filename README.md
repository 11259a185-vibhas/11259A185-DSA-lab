## Supporting record

[All codes and outputs](DSA-Lab/All_Codes_and_Outputs.md) provides a combined reading copy. Sample inputs and terminal transcripts remain in the matching folders under `DSA-Lab/`. The `.c` files at the repository root are the individual experiment submissions.

## Compile and run

With GCC installed, run from the repository root (replace `1` with the experiment number):

```sh
gcc -std=c11 11259A185_exp1.c -o exp1 -lm
./exp1
```

On Windows, run `exp1.exe`. On Linux/WSL, the saved input can be used with:

```sh
./exp1 < DSA-Lab/Experiment-01-Array_Operations/input.txt
```
